中文

感谢使用「Stitch Translate 翻译缝合怪」（下称「本扩展」）。我们重视你的隐私。本政策说明扩展如何处理信息。

我们收集哪些数据

本扩展不运营后端服务器，也不会把你的翻译内容、API Key 上传到开发者服务器。

  • 本地配置：界面语言、源/目标语言、引擎顺序、AI 模型配置（含 API Key、接口地址、提示词）等保存在浏览器扩展本地存储（chrome.storage.local）中。
  • 待翻译文本：仅在你主动翻译时使用（Popup 输入、网页选中文本或右键菜单），用于向翻译服务发起请求。

数据发送到哪里

  • Google 翻译 / Bing 翻译：启用对应引擎时，待翻译文本会发送到 Google 或 Microsoft 的翻译接口，并受其各自隐私政策约束。
  • 自定义 AI 模型：若你配置了 OpenAI 兼容接口，待翻译文本与提示词会发送到你填写的接口地址（例如 OpenAI 或第三方兼容服务）。请自行阅读该服务商的隐私政策。

权限说明

  • storage：保存本地配置。
  • activeTab / 内容脚本：在网页上显示选中翻译浮标与面板。
  • contextMenus：提供右键「翻译」菜单。
  • 主机权限：默认包含 Google、Bing、OpenAI 官方域名；其他自定义 AI 域名仅在你保存/测试/翻译时通过可选权限弹窗授权。

数据保留与删除

配置仅保存在本机浏览器中。卸载扩展或在浏览器中清除扩展数据即可删除。开发者无法远程访问或删除你的本地数据。

儿童隐私

本扩展面向一般用户，不面向 13 岁以下儿童收集信息。

政策变更

若本政策有重大更新，我们将在本页面更新日期。继续使用即表示你知悉更新后的政策。

联系方式

如有隐私相关问题，请通过项目仓库 Issues 联系： github.com/leo95123/stitchTranslate

English

Thank you for using Stitch Translate 翻译缝合怪 (“the Extension”). This policy explains how information is handled.

Data we handle

The Extension does not operate a developer backend and does not upload your translation text or API keys to our servers.

  • Local settings: UI language, language pair, engine order, and AI model settings (including API keys, endpoints, and prompts) are stored in the browser via chrome.storage.local.
  • Text to translate: Used only when you explicitly translate (popup input, page selection, or context menu) to call translation providers.

Where data is sent

  • Google Translate / Microsoft Bing Translator: When enabled, text is sent to Google or Microsoft endpoints under their respective privacy policies.
  • Custom AI models: If configured, text and prompts are sent to the endpoint URL you provide (e.g. OpenAI-compatible APIs). Review that provider’s privacy policy separately.

Permissions

  • storage: Save local preferences.
  • activeTab / content scripts: Show the selection FAB and translation panel on web pages.
  • contextMenus: Provide a right-click translate action.
  • Host access: Google, Bing, and OpenAI hosts are declared by default; other custom AI hosts are requested via optional permissions when you save, test, or translate.

Retention & deletion

Settings remain on your device. Uninstalling the Extension or clearing extension data removes them. We cannot remotely access or delete your local data.

Children

The Extension is not directed at children under 13.

Changes

We may update this page and the “Last updated” date when the policy changes materially.
