隐私政策 / Privacy Policy · 2026-08-13

中文

本扩展不收集、不上传你的数据到开发者服务器。配置与 API Key 仅保存在本机浏览器本地存储。

仅在你主动翻译时，文本会发送至：

  • 已启用的 Google / Bing 翻译服务；和/或
  • 你自行配置的 AI 接口地址。

卸载扩展或清除扩展数据即可删除本地配置。

联系： GitHub Issues

English

This extension does not collect or upload your data to developer servers. Settings and API keys stay in local browser storage only.

Text is sent only when you translate, to:

  • enabled Google / Bing translator services; and/or
  • AI endpoints you configure yourself.

Uninstall the extension or clear extension data to remove local settings.

Contact: GitHub Issues
