# GitHub Pages

隐私政策由仓库 `docs/` 目录通过 GitHub Pages 发布。

## 首次启用（只需一次）

1. 打开 https://github.com/leo95123/stitchTranslate/settings/pages  
2. **Build and deployment** → **Source** 选 **Deploy from a branch**  
3. **Branch** 选 `main`，文件夹选 `/docs`  
4. 点击 **Save**

约 1 分钟后访问：

https://leo95123.github.io/stitchTranslate/privacy-policy.html
